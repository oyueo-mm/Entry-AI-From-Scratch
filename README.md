# Entry AI From Scratch
Entry로 다양한 인공지능 및 머신러닝 알고리즘을 직접 구현해 보는 프로젝트입니다.

---

# 한국어
## 엔트리란?
[엔트리(Entry)](https://playentry.org/)는 블록을 조립하여 프로그램을 만드는 **블록 기반 프로그래밍 플랫폼**입니다.

변수, 리스트, 조건문, 반복문, 함수 등의 기능을 제공하며, 이 프로젝트에서는 이를 이용하여 머신러닝과 딥러닝 알고리즘을 구현합니다.

---

## `.ent` 파일을 블록 코딩으로 보는 방법
이 저장소의 구현은 `.ent` 파일로 제공됩니다. `.ent` 파일은 엔트리 작품 파일입니다.

1. GitHub에서 원하는 `.ent` 파일을 선택합니다.
2. `Download raw file`을 눌러 파일을 다운로드합니다.
3. [엔트리](https://playentry.org/)에 접속합니다.
4. **작품 만들기**로 들어갑니다.
5. **오프라인으로 작품 불러오기** 이용하여 다운로드한 `.ent` 파일을 선택합니다.
6. 작품이 열리면 블록 코딩 화면에서 구현된 알고리즘을 확인할 수 있습니다.

## 목적
이 프로젝트의 목적은 인공지능 알고리즘을 단순히 사용하는 것이 아니라 **직접 구현하면서 알고리즘의 내부 동작을 이해하는 것**입니다.

PyTorch, TensorFlow, scikit-learn과 같은 고수준 라이브러리에 의존하지 않고, 가능한 한 알고리즘의 핵심적인 계산 과정을 Entry의 블록으로 구현합니다.

# English
## What is Entry?

[Entry](https://playentry.org/) is a **block-based programming platform** where programs are created by connecting visual blocks.

It provides features such as variables, lists, conditions, loops, and functions. In this project, these features are used to implement machine learning and deep learning algorithms.

---

## How to View `.ent` Files as Block Code
The implementations in this repository are provided as `.ent` files. An `.ent` file is an Entry project file.

1. Select the `.ent` file you want to view on GitHub.
2. Click `Download raw file` to download it.
3. Go to [Entry](https://playentry.org/).
4. Open the **Create** workspace.
5. Use **Open Offline File** and select the downloaded `.ent` file.
6. Once the project is loaded, you can view the implementation in the block-coding workspace.

## Purpose
The purpose of this project is to **understand how AI algorithms work internally by implementing them from scratch**.

Instead of relying on high-level libraries such as PyTorch, TensorFlow, or scikit-learn, the project attempts to implement the core computational processes of each algorithm using Entry's block-based programming environment whenever possible.
