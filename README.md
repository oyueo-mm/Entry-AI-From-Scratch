# Entry AI From Scratch

Entry로 인공지능과 머신러닝 알고리즘을 직접 구현해 본 것들을 모아둔 저장소입니다.

라이브러리를 사용하는 것보다 알고리즘 자체를 이해하는 데 관심이 있어서, Entry의 블록만으로 하나씩 구현해 봤습니다.

## 구현한 것

### Machine Learning
- 선형 회귀
- 로지스틱 회귀
- KNN(분류와 회귀)
- 군집 알고리즘(DBSCAN, K-Means, OPTICS, AGNES, DIANA, PAM, SOM, LVQ)
- 유전 알고리즘

### Neural Network
- 인공신경망 (ANN)
- CNN
- RNN
- GAN
- DCGAN
- VAE
- CVAE
- β-VAE
- HVAE

### Reinforcement Learning
- Q-Learning
- DQN

### Computer Vision
- 이미지 픽셀 처리
- 컴퓨터 비전 관련 알고리즘

### 기타
- 활성화 함수(GELU, LeakyReLU, Mish, SeLU, 계단함수, SoftPlus, SiLU, Sigmoid, ReLU, Tanh, ELU) 구현

## 이 저장소에 대해

각 폴더에는 Entry로 만든 프로젝트 파일과 실험 과정에서 사용한 자료들이 들어 있습니다.

대부분 직접 구현하면서 공부한 것들이라 코드가 깔끔하게 정리되어 있거나 최적화되어 있지는 않습니다.

완성된 라이브러리를 만드는 것이 목적이 아니라, 알고리즘을 직접 만들어 보면서 동작 원리를 이해하는 것이 목적이었습니다.

특히 신경망의 경우 순전파, 손실 계산, 역전파, 가중치 업데이트까지 가능한 한 직접 구성해 보았습니다.

그러나 엔트리 자체의 계산적 한계로 대부분의 신경망은 파이썬에서 학습한 가중치를 불러와서 순전파를 하는 것에 그쳤습니다.

## 파일

Entry 프로젝트는 `.ent` 파일로 저장되어 있습니다.

Entry에서 프로젝트 파일을 불러오면 구현 내용을 확인할 수 있습니다.

## 목적

이 저장소는 인공지능을 공부하면서 직접 구현해 본 것들을 기록하기 위한 저장소입니다.

처음에는 간단한 회귀와 분류부터 시작해서 신경망, 생성 모델, 강화학습 등으로 범위를 넓혀가며 구현했습니다.
